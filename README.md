# Greenbin-rewards
A digital waste management platform that rewards users with Green Points for responsible waste disposal and recycling.

🔗 Project Link
https://green-bin-rewards-add51dfe.base44.app

📌 About the Project
GreenBin Rewards allows users to interact with a digital waste management system, request waste pickups, track recycling activities, and earn rewards for responsible waste disposal.
