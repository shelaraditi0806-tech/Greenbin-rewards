# Greenbin-rewards
A digital waste management platform that rewards users with Green Points for responsible waste disposal and recycling.

🔗 Project Link
https://green-bin-rewards-add51dfe.base44.app

Users can request waste pickups, track their recycling activities, earn Green Points based on the amount of waste recycled, and redeem their accumulated points for rewards.

### ✨ Features
* 👤 User registration and login
* 🗑️ Waste pickup requests
* ♻️ Recycling guide
* 🌱 Green Points reward system
* 💰 Reward redemption
* 📊 User dashboard
* 👨‍💼 Admin dashboard
* 📩 Contact and support section
* 📱 Responsive design

### 🛠️ Technologies Used
* HTML5
* CSS3
* Bootstrap
* JavaScript

### 🎯 Objective
The main objective of GreenBin Rewards is to combine technology with environmental sustainability by encouraging people to recycle and dispose of waste responsibly.

### 🚀 Future Improvements
* Mobile application

* Integration with recycling centers
* Real-time notifications
